\# GlobeTrek 



\*\*A Sri Lankan Travel and Tourism Booking Website\*\*



GlobeTrek is a web-based travel platform designed to help users explore destinations, discover hotels and travel packages, and manage their bookings.



The system also includes administrative and staff interfaces for managing the platform's operations.



\## Features



\### Customer features

\- Browse travel destinations across Sri Lanka.

\- Explore available hotels and travel packages.

\- View detailed destination, hotel and package information.

\- Register and log in to an account.

\- Make and manage travel bookings.

\- View account information and booking history.

\- Submit enquiries and view messages.



\### Administration features

\- Admin dashboard.

\- Manage travel packages.

\- Manage staff accounts.

\- Manage bookings.

\- View reports.

\- Manage system settings.



\### Staff features

\- Staff dashboard.

\- Manage bookings.

\- Manage packages.

\- Respond to customer enquiries.

\## Local Setup



1\. Install XAMPP.

2\. Clone or download this repository.

3\. Place the project folder inside the XAMPP `htdocs` directory.

4\. Start Apache and MySQL using the XAMPP Control Panel.

5\. Create a MySQL database named `travel\_db`.

6\. Configure the database connection in `php/db.php` to match your local MySQL settings.

7\. Set up the database tables before running the application.

8\. Open the website through:



```text

http://localhost/GlobeTrek/

```



\*\*Note:\*\* The database SQL setup file will be provided separately when available.
